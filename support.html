Report a bug (get it fixed faster)

The fastest route is email — copy the template below into hello@zpad.app and fill it in:

ZPad version:  (menu-bar icon → About / Settings → System)
macOS version:  ( → About This Mac)
Apple Silicon / RAM:

What happened:
  …

What I expected:
  …

Steps to reproduce:
  1. …
  2. …

Does it happen every time?  yes / no
Anything unusual?  (external displays, custom shell, VPN, other utility apps)
  • Include the version — half of all bug reports are solved by “update to the latest build”.
  • Never paste API keys or license keys into public places. Email is fine for license specifics.

Request a feature

Feature requests are welcome — several shipped features started as user emails. Email us and describe the workflow you want, not just the feature: the “why” shapes the design. Check the changelog first — it might already exist.
