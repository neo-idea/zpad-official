Highlights

  • AI Chat tabs — bring your own OpenAI-compatible provider (OpenAI, DeepSeek, local Ollama): streaming replies, Markdown with copyable code blocks, per-chat model overrides, auto-titles, pin/rename/clear. API keys live in the macOS Keychain; history stays local. Read the setup guide →
  • Command palette upgrades — “New Chat” action; fuzzy-search and switch chat tabs alongside web and terminal tabs.
  • Release automation — tagged builds publish signed DMGs to GitHub Releases automatically.

v1.0.0

STABLE 2026-08-09 · the first tagged, distributable build

Added

  • Sliding status-bar panel with hot-zone activation and ⌘⌥P global toggle.
  • Multi-tab web browser (WKWebView) with favicons, history, and bookmark management.
  • Built-in terminal powered by SwiftTerm with per-tab scrollback preservation.
  • Four display modes — side panel (left/right), centered modal, navbar-anchored.
  • Workspaces & favorites for organizing tabs and bookmarks.
  • Localization — English + 简体中文 via String Catalogs.
  • Licensing — offline Ed25519 verification, in-app purchase UI, 30-day trial, self-serve device management, Stripe checkout, license emails.
  • Sparkle plumbing for auto-updates; observability and activation UX hardening.

Fixed

  • Panel-hiding after switching to navbar mode; navbar positioning and focus issues.
  • Terminal command field keyboard focus in the popover.
  • Security review findings: timing-safe license lookup, device-field sanitization, CSP headers.
