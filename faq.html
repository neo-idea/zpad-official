General

What exactly is ZPad?+

A macOS status-bar panel that keeps a real multi-tab browser, a real terminal, a code editor and an AI chat one hotkey away — ⌘⌥P from any app. Slide it out, work, slide it away; tabs, scrollback, and sessions are preserved. Native Swift + SwiftUI, not Electron.

Who is it for?+

Anyone who lives on a Mac and toggles between docs/web and a shell: developers, data folks, writers who research, students, sysadmins. If you've ever cmd-tabbed to Terminal 40 times a day, ZPad is for you.

Which Macs and macOS versions are supported?+

macOS 15.1 (Sequoia) or later, Apple Silicon (M1–M4). Release builds are arm64 only; there is no Intel build today.

How is this different from Spotlight or Raycast?+

Launchers start apps and hand you off. ZPad is the destination: the browser and terminal live inside it permanently, state preserved, zero launch latency, one hotkey to show/hide. See the feature summary.

Does it replace my main browser or terminal?+

It can, but it shines as your quick-access surface: docs lookups, dashboards, git/build commands, Claude Code sessions. Your heavy sessions stay wherever they are; ZPad removes the switching tax between them.

Features

Can I run Claude Code / other CLI agents in ZPad?+

Yes — the terminal is a real emulator (SwiftTerm) with a full PTY. claude, aider, git, docker, ssh, vim: if it runs in Terminal.app it runs here. Scrollback survives every hide/show.

What are workspaces?+

Saved, switchable sets of tabs — one for each project or context. Each workspace keeps its own browser tabs, terminal sessions, and layout. Switching is instant and lossless. See the guide.

Is there a command palette?+

Yes — ⌘K opens it globally (even while the panel is hidden); ⌘⇧A opens a tab-switcher scope. Fuzzy-search everything: actions, tabs, workspaces.

Does ZPad include an AI chat?+

Yes, as a beta: bring your own OpenAI-compatible provider (OpenAI, DeepSeek, local Ollama…) — API key stored in Keychain, history stored locally. You control the model, temperature, and system prompt. Setup: guide.

Which display modes exist?+

Four: side panel right (default), side panel left, centered modal, and dropdown under the menu-bar icon. Toggle directly with ⌘⌥1/2/3 or set a default in Settings.

Can I change the language?+

Yes — English and 简体中文 built in; follow the system or force either in Settings → Primary → Language.

Privacy & security

Does ZPad spy on me?+

No. Analytics is opt-in and off by default. Browsing data, terminal sessions, chat history, and API keys stay on your Mac (keys in Keychain). The complete list of network calls — favicon lookups, licensing, optional update checks — is published in the Privacy Disclosure.

Are the builds signed and notarized?+

Yes — Developer ID signed, Apple notarized, and stapled, published only via the official download page. If macOS calls a download “damaged”, don't bypass Gatekeeper: re-download from the official page.

What does the license server see?+

License lookups send your key, device identifier, and app version — used only to enforce device limits and revocation. No browsing or terminal data ever leaves your Mac. See the privacy matrix.

Troubleshooting

macOS says the app is “damaged”+

Delete it and re-download from the official download page. Genuine notarized builds open cleanly; never bypass Gatekeeper warnings. Full steps in the troubleshooting guide.

⌘⌥P does nothing+

Another app (Raycast, BetterTouchTool, input-method switchers) probably owns the shortcut. Check its settings, or use the menu-bar icon / mode shortcuts ⌘⌥1/2/3 instead.

The panel pops out when I don't want it+

That's the screen-edge hot zone. Turn it off: Settings → Behavior → hot-zone trigger, and keep hotkey-only summoning.

License activation fails+

Check the pasted key is complete and you're online; if you're at 3 Macs, deactivate one first. Still failing — email us with your order ID. Details: license guide.

How do I update ZPad?+

Settings → System → Check for updates (signed metadata), or download the latest DMG and drag over — settings and license carry over. Enable automatic checks in Settings → Privacy if you prefer hands-off.
