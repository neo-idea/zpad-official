Field kit · Homepage banner

Scripts for your
homepage banner.

ZPad's homepage banner can run your own HTML, CSS, and JavaScript. Copy a recipe below, paste it into Settings → Homepage Banner → Custom HTML, and the panel homepage becomes yours.

How to install 00 / SETUP

  1. Open Settings → Homepage Banner. Use the gear in the panel header or ⌘, from the panel.

  2. Choose “Custom HTML” as the banner style, then paste a script into the editor (it replaces the sample — that's fine).

  3. Save. The homepage now renders your markup at its real banner size. Scripts up to 512 KB are accepted; edit or clear anytime.

Good to know

JavaScript runs; links open outside the banner instead of navigating it; storage is non-persistent (a fresh slate each load). Scripts that fetch remote APIs — like the Hitokoto recipe — need an internet connection and show their own fallback text offline.

<script>
// 一言API，支持跨域，直接浏览器请求
async function fetchHitokoto() {
  try {
    const res = await fetch('https://v1.hitokoto.cn/');
    const data = await res.json();
    document.getElementById('hitokoto-text').innerText = data.hitokoto;
    document.getElementById('hitokoto-from').innerText = `—— ${data.from}`;
    document.getElementById('hitokoto-type').innerText = getHitokotoTypeName(data.type);
    document.getElementById('hitokoto-src').innerText = data.from_who || data.from;
  } catch (err) {
    document.getElementById('hitokoto-text').innerText = '获取一言失败';
    document.getElementById('hitokoto-from').innerText = '网络或接口异常';
  }
}

// 一言type编码转中文名称
function getHitokotoTypeName(t) {
  const map = {
    a: '动画', b: '漫画', c: '游戏', d: '文学',
    e: '原创', f: '网络', g: '其他', h: '影视',
    i: '诗词', j: '网易云', k: '哲学', l: '谚语'
  };
  return map[t] || '未知';
}

fetchHitokoto();
</script>
